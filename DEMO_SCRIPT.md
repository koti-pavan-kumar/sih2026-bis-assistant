## 🎤 SIH PRESENTATION — JUDGE Q&A CHEAT SHEET

### Questions Judges WILL Ask:

**Q: "What makes this different from ChatGPT?"**
> "ChatGPT gives generic answers from its training data. ManakMitra uses RAG — Retrieval Augmented Generation — to search our indexed BIS standards and cite specific IS numbers with exact clause references. Every answer is traceable to an official government document. Plus, it speaks 22 Indian languages, which ChatGPT handles poorly for Indian legal/regulatory content."

**Q: "How many standards do you have?"**
> "We currently have 28 indexed standards covering electronics, construction, food safety, leather, and more. Our auto-fetch feature continuously adds new standards as BIS publishes them — the system grows automatically."

**Q: "Where is user data stored?"**
> "Currently in browser localStorage for the MVP. For production, we plan to use PostgreSQL with JWT-based authentication for server-side user management."

**Q: "How do you handle hallucination?"**
> "Three mechanisms: First, RAG retrieval limits responses to only what's in our indexed documents. Second, citation verification checks that every IS number mentioned actually exists in our index. Third, our 6-section format forces structured, verifiable output rather than free-form text."

**Q: "Can this work offline?"**
> "Yes — with Ollama running a local LLM on the user's machine. The ONNX embeddings and FAISS index work offline. Only the Gemini API calls need internet. We can swap in any local LLM for fully offline operation."

**Q: "How will you scale?"**
> "The architecture is modular — embedding model, vector store, and LLM are all swappable. For production, we'd add PostgreSQL for user data, Redis for caching, and deploy on Kubernetes. The ONNX embedding model runs at 80MB, well within any cloud tier."

**Q: "What's the business model?"**
> "Free for MSMEs — this is a public good. Funded through government deployment (BIS, MSME Ministry). No ads, no data selling. The auto-fetch keeps the knowledge base current without manual maintenance."

**Q: "What about data privacy?"**
> "Queries are processed in real-time and not stored on our server. User chat history stays in the browser. No PII is sent to the LLM — only the query text and retrieved standard excerpts."

**Q: "How accurate are the responses?"**
> "Responses are directly tied to indexed BIS standard documents. When the AI references IS 14543, it's citing the exact document in our knowledge base. The confidence comes from the source, not from the AI's training data."

**Q: "What's next after SIH?"**
> "Three roadmap items: (1) Add 500+ BIS standards through automated scraping, (2) Real PostgreSQL authentication with government SSO, (3) Mobile app for field inspectors using BIS testing centres on-the-go."
