🏛️ Key Features & Technology Choices
🧠

RAG Architecture

Retrieval Augmented Generation ensures every answer is grounded in actual BIS standard documents, not AI hallucination.

⚡

ONNX Runtime

Replaced PyTorch (500MB) with ONNX (80MB). Same accuracy, 10x less memory. Fits free hosting tier.

🌍

22 Indian Languages

Auto-detect → translate → RAG → translate back. Works for Hindi, Telugu, Bengali, Tamil, Marathi, and more.

🔄

Auto-Fetch

Automatically scrapes bis.gov.in for new standards, downloads PDFs, and indexes them — zero manual work.

📍

Office Finder

25+ BIS testing centres with geolocation, distance sorting, product-based filtering, and Google Maps integration.

📝

Certification Guide

Step-by-step guides for ISI Mark, Hallmark, Eco Mark, CMVR, and MSME Udyam with official government links.
