🔍 Discovery Problem

MSMEs don't know which BIS standards apply to their specific products. Manual research across 28,000+ standards is impossible.

🌐 Language Barrier

BIS documents are in English. 90% of MSME owners speak regional languages. They can't read the standards they need to follow.

📋 Compliance Gap

No step-by-step guidance on how to obtain BIS certification. MSMEs face penalties for non-compliance due to lack of awareness.

Our Solution
💬

Ask in Your Language

Ask questions in Hindi, Telugu, Bengali, Tamil, or any of 22 Indian languages. ManakMitra understands and responds in the same language.

📋

6-Section Structured Response

Every answer includes: Applicable IS Standards, Testing Requirements, Where to Test, Mandatory?, Certification Process, Documents Required.

🔍

Verified Sources Only

RAG architecture ensures every answer cites specific IS numbers and clause references. No AI hallucination — only verified government documents.

🔄

Auto-Fetch New Standards

Automatically monitors bis.gov.in for new standards, downloads PDFs, and indexes them. Knowledge base grows without manual intervention.

📍

Find Testing Centres

Locate 25+ BIS testing offices nearest to you with Google Maps navigation. Filter by product type and services offered.

📝

Certification Guidance

Step-by-step guides for ISI Mark, Hallmark, Eco Mark, CMVR, and MSME Udyam registration with direct links to official portals.

System Architecture
🌐

React Frontend

7 pages, dark mode, 22 languages, responsive UI. Deployed on Vercel.

⚡

FastAPI Backend

Async Python server with REST APIs for query, standards, offices, certifications.

🧠

ONNX Embeddings

all-MiniLM-L6-v2 model. 80MB, 384-dim vectors. No PyTorch dependency.

📊

FAISS Vector Store

115+ document chunks indexed. Cosine similarity search for fast retrieval.

🤖

Gemini LLM

gemini-3.6-flash for structured response generation. Template fallback available.

🌍

Translation Engine

deep-translator + langdetect. Auto-detect → translate → RAG → translate back.

🔄

Auto-Fetch Pipeline

BeautifulSoup scraper → PDF parser → text chunker → embedding → FAISS index.

🏛️

BIS Data APIs

28 standards, 25+ offices, 5 certification types, Haversine distance calc.
