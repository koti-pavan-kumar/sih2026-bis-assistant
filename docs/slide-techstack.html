Why These Technologies?
  • ONNX over PyTorch — 10x smaller memory footprint (20MB vs 500MB), same accuracy
  • FAISS over Pinecone — Free, offline-capable, no cloud dependency
  • FastAPI over Flask — 3x faster async performance for concurrent queries
  • Gemini over OpenAI — Free tier, multilingual support, no API cost
  • deep-translator — Supports 22 Indian languages including Telugu, Tamil, Bengali
Key Differentiators vs Existing Solutions
  • vs ChatGPT: Domain-specific RAG with verified BIS documents — no hallucinations on legal info
  • vs BIS Website: Plain English explanations of technical standards + multi-language support
  • vs Consultants: Free, instant, 24/7 — no appointment needed
  • vs Manual Research: 6-section structured answer in 20 seconds vs hours of document searching
System Capabilities
  • RAG Pipeline: Query → Embed → Search FAISS → Retrieve chunks → Gemini generates answer
  • Live Pipeline: Auto-fetch new standards from bis.gov.in, re-index automatically
  • Multilingual: Auto-detect language → translate to English → process → translate back
  • Per-user Isolation: JWT auth ensures each user sees only their own chat history
  • Offline Ready: ONNX + FAISS can run without internet for embedding + search
Scalability Roadmap
